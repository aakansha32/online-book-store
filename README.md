# Online Book Store

A simple Online Book Store project developed using Java and Maven.

## Technologies Used
- Java
- Maven
- JUnit
- Git
- GitHub
- GitHub Actions
- Jira

## CI/CD Pipeline

The project uses GitHub Actions for Continuous Integration.

Pipeline stages:

Code → Build → Test → Package

## Jira Integration

Jira issue keys are included in Git commit messages for traceability.
